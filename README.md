# ROCK ESPORTS Website

## How to publish
1. Create a GitHub repository (example: `rock-esports-official`).
2. Upload `index.html`, `style.css`, `script.js` and the `assets` folder.
3. In GitHub: Settings → Pages → Deploy from branch → `main` → `/ (root)` → Save.
4. Your public website will get a GitHub Pages address.

## Important
Only people with write access to your GitHub repository can edit the website files. Everyone else can only view the public website.
To keep editing restricted to you, do not give other people repository write/admin access.

## Editing
- Main text: `index.html`
- Design/colors/layout: `style.css`
- Small interactions: `script.js`
- Photos/logos can be added later inside `assets/` and referenced from `index.html`.
